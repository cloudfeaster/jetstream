# Contributing

This repo's development environment is set up by [jetstream](https://github.com/cloudfeaster/jetstream). Install [uv](https://docs.astral.sh/uv/), then:

```bash
source cfg4dev.sh
```

jetstream's docs, in `.jetstream/docs/`, say how to work here:

- [dev-workflow.md](.jetstream/docs/core/dev-workflow.md): how a change gets to `main`
- [dev-environment.md](.jetstream/docs/core/dev-environment.md): the tools and checks$pack_docs
